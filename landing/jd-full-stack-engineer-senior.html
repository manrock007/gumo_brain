How we build

No sprints. No staging. No hand-offs.

Every feature runs a 10-stage pipeline where Claude does the heavy lifting and a human DRI - one directly responsible engineer - drives every step.

01

Contract-first

A frozen backend↔frontend contract + simulator before any code - so both sides build in parallel against the same reality.

02

AI-native execution

Claude Code writes most of the code. You direct it, review it, and verify it by running the app - not by trusting the diff.

03

One Design System

Every screen is composed from a living component library; anything new is contributed back. Build it in the system, not the feature.

04

Flags, not staging

Verify locally, merge dark behind a feature flag in production, dogfood there, flip it on. Rollback is one click.

05

Artifacts, not meetings

Each step outputs a structured doc the next step's Claude reads directly. Three synchronous touchpoints per feature - that's it.

06

Done = demonstrated

Screenshots, green gates, a flag, and a one-click rollback - never just "code written."

What we look for

Depth on both sides of the stack - and judgment.

Must-haves

  • 5+ years shipping production full-stack software - we index on the scope of what you've shipped, not tenure
  • Python depth - Django/DRF (or comparable) in production: data modelling, migrations, auth, background jobs, tests, Postgres, performance under real load
  • JavaScript/TypeScript depth - React on web plus React Native, or a shipped comparable mobile app
  • Architecture judgment - API/contract design, failure modes, scalability trade-offs; you can review someone else's design and make it better in one pass
  • AI-native working style - an AI coding tool is already your daily driver; you direct, review, and correct its output fast, and verify by running the app
  • Written clarity - your contracts are frozen documents two build tracks work against
  • Ownership and review leadership - you drive features to live without being chased, and make the people around you better
  • Client-facing composure - scope, demo, absorb critique, iterate live; you'll lead engagements early

Nice-to-haves

  • Feature-flag-gated rollouts; observability and product analytics (Mixpanel, Sentry)

  • DevOps - GCP, Docker, CI, systemd; enough to self-serve a deployment
  • Mobile releases (TestFlight / Play Console), push-notification plumbing
  • Prior mentoring or tech-lead experience
